The original is preserved at /workspace/research/SAC-RWB. This directory is Neo's

## Correctness repairs

- Actor outputs exactly one acceleration per observed virtual vehicle. Preserve
  batch shape; never flatten a 98-action output and zip it to vehicle IDs.
- Replay validates state/action shapes and receives actual terminal masks.
  Entering the intersection ends access control; time-limit truncation alone
  does not zero the SAC bootstrap. All acted-on vehicles must have a transition.
- `baseline.py` replaces broken training/evaluation entrypoints. It initializes
  dimensions, uses explicit checkpoints, validates reload predictions, closes
  SUMO in finally, and writes separate training and evaluation records.
- Waiting features are indices 10:18 in the 98-D observation, not 12:20.
- Observation rotation uses modulo eight rather than seven, so every direction
  appears once. This additional upstream defect was found during implementation.
- Newly entering vehicles are compared by immutable vehicle ID, rather than full
  mutable vehicle dictionaries. Otherwise a vehicle moving within a junction can
  be counted as a new entry every step, corrupting the CR denominator.
- Paper Eq. (3) mean-rank subtraction is implemented including tied ranks;
  replace hard-coded rank minus 5.5. Waiting normalization uses paper's 300 s.
- Paper's critic LR 4e-4 replaces code's 3e-4; actor remains 3e-4.
- Negative predicted-risk reward follows author code and collision=1 labels.
  The sign ambiguity in the paper's reward notation remains documented.
- Training-only stopped-in-junction <0.1 m/s proxy is restored within selected
  junctions. These vehicles are removed only in training. Actual collision IDs
  and proxy IDs are recorded separately. Unsubscribe before removal to avoid
  stale SUMO 1.12 subscriptions. Evaluation disables this proxy and risk model.
- Zero padding is used consistently during predictor training/inference.
- No fabricated safe example is generated by changing an action to braking.
- Risk reward is computed in eval/no_grad mode. CUDA errors fail the experiment
  instead of manufacturing risk=0.5 or silently skipping training batches.
- Seed Python/NumPy/Torch and explicitly configure the SUMO seed. Each episode
  uses seed+episode and sumo_seed+episode; these are intentional documented seeds.
- The predictor's ongoing per-vehicle histories are cleared between episodes.

## Metrics and limitations

AWT is the mean of recorded direction-level average cumulative waiting values
over junctions, directions and the stated monitor window. AQL is the corresponding
mean queue count. Collision output explicitly counts unique collision-involved
vehicle IDs divided by junction entries in the same window. This is not a count
of unique physical crash events; it cannot automatically equal the paper's CR.
Physical collisions are additionally filtered to the selected junctions; detailed
TraCI collision pairs are logged, counting a new pair/lane event at the onset of
a contiguous collision report. Whole-network collision IDs remain a separate
diagnostic. Neither operational rate is claimed to be the paper's exact CR.
Also retain whole-episode collision/proxy counts, entries, arrivals and unfinished
vehicles. Initial reset traffic is excluded from the explicitly named
`departures_after_reset` and `arrivals_after_reset` fields.

Table II's 1500 rounds/steps, Table III's window/three seeds, single versus
multi-junction scenario and physical collision denominator remain unresolved.
No exact reproduction claim is valid until protocol correspondence is established.
Short pilot metrics are diagnostic and are not a substitute for 500-episode runs.

seconds after diagnosing stale vehicle subscriptions. Its partial data must not
be included in final results. `pilot-002` is a new run after the lifecycle fix.

v2/v3 runs archive all five relevant source files and code SHA256 hashes at startup.

Full `resume.pt` checkpoints are episode-boundary resumable with replay/risk
buffers and RNG/optimizer state. Per-episode `checkpoint-NNNN.pt` files are compact
evaluation checkpoints. Only the latest full resume file is retained, using an
atomic rename, rather than storing 500 copies of a million-transition buffer.
